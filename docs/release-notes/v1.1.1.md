# mermaid-tty v1.1.1

More Mermaid syntax draws, including bold and italic labels. Kitty and Ghostty can show Mermaid's own picture of a diagram. The validator now rejects drawings that misread frames, line styles or config, and installing no longer shows a config notice.

## Install

```sh
claude plugin marketplace add D0n9X1n/mermaid-tty
claude plugin install mermaid-tty@mermaid-tty --config theme=default
```

Needs Claude Code 2.1.287 or later. Already on v1.0.0? Run `claude plugin update mermaid-tty@mermaid-tty`.

## What's new

- **Pictures in kitty and Ghostty (#22).** With mermaid-cli 11 or 12 (`mmdc`) on your PATH, kitty and Ghostty first show a diagram as text, then as Mermaid's own picture. This doesn't apply under tmux, screen or zellij. Pictures are only drawn for plain diagrams the text renderer understands: Chromium runs with no network access, and the SVG Mermaid draws must pass a strict allowlist before it becomes a PNG. `/mermaid-tty text` keeps text drawings.
- **Bold and italic (#15).** Markdown `**bold**` and `*italic*` draw as bold and italic text in flowchart Markdown strings, and in state, class, ER and mindmap labels, wherever Mermaid shows them.
- **More flowchart syntax (#4, #16).**
  - Text-form two-headed links such as `A <-- t --> B`, and mixed end marks such as `<--o`.
  - Partly quoted labels like `["a" b]`, `@{ … }` split over lines, and `#…;` character codes.
  - A literal `\n` in a label draws as a line break.
- **More sequence syntax (#4, #17).**
  - `;` between statements, `#` comments, and `autonumber` with a start, a step, `off` and restarts.
  - Keyword and number participant ids, and `box` titles.
  - Frames nested inside or beside a `box`.
  - Columns follow Mermaid's participant order.
- **ER generics (#16).** `~T~` shows as `<T>` wherever Mermaid shows it so.
- **Directives (#16).** A whole-line `%%{init: …}%%` reads as config, like frontmatter.
- **Cleaner layouts (#8).** In state, class and ER diagrams:
  - two edges between the same two nodes are drawn side by side;
  - labels on long back edges sit by their turn;
  - inheritance heads stand a cell apart.
- **Install without a notice (#5).** The install line saves the default theme.
- **Decimal frontmatter values (#7)** read as numbers, as in Mermaid.

## Stricter fallbacks

These drew before but could differ from Mermaid, so they now show the source:

- **Config (#25).** A config setting from frontmatter or a directive is accepted only if it's checked not to change what Mermaid shows. Examples that now fall back: `showSequenceNumbers`, hidden axis labels, `wrap`, colours and font sizes.
- **Frames.**
  - An edge that crosses a subgraph frame it doesn't belong to (#19, #13).
  - A sequence frame that would cover participants Mermaid's frame leaves out (#24).
- **Lines.**
  - An edge drawn in another line style, or one whose style doesn't show on its own path (#27, #18).
- **Sequence lexing.** An empty `accTitle:` or `accDescr:`, and lines whose line break Mermaid's lexer drops.
- **Flowchart ids.** An id Mermaid reads as a keyword, such as `end-x` or `1style` (#14).

`fa:` icons, `$$…$$` math and `htmlLabels: false` always show the source, by design (#20).

## Fixes

- A dotted sequence self-message with two heads now draws dotted.
- A backslash before a `#…;` code in a Markdown label falls back instead of drawing wrong (#26).
- The Windows end-to-end tests no longer trip on Claude Code's spinner or its `/copy` picker (#10, #31).

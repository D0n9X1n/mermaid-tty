# mermaid-tty v1.0.0

The first release. In Claude Code, each closed mermaid code fence in a reply is drawn as a colored, flat, box-drawing diagram sized to your terminal, on macOS, Linux and Windows. The transcript keeps the source.

## Install

```sh
claude plugin marketplace add D0n9X1n/mermaid-tty
claude plugin install mermaid-tty@mermaid-tty
```

Needs Claude Code 2.1.287 or later.

## What's in it

- 13 diagram types: flowchart (and `graph`), sequence, state, class, ER, mindmap, gantt, pie, gitGraph, timeline, journey, xychart and quadrant. The README's support table lists the headers each one reads.
- Exact widths for CJK labels. A diagram that can't be drawn exactly as Mermaid shows it falls back to its source: mermaid-tty never draws part of a diagram, or text Mermaid would show differently.
- Every drawing passes a validator before it is shown. CI attacks the validator with tens of thousands of mutated drawings on every change, and none gets through.
- Colors follow your Claude Code theme, or pick nord, dracula, gruvbox, solarized or mono. Mono tells roles apart by glyphs alone.
- `/mermaid-tty source` shows every diagram as its Mermaid source, and `/mermaid-tty diagram` draws them again; `/copy` copies the exact source.
- Tested end to end inside real Claude Code on Linux, macOS and Windows.
